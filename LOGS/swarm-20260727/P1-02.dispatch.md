## Validation to add (architecture invariant A-05 — "identity is not location")

Add a constructor and an error type. These names are binding:

```rust
#[derive(Clone, Debug, thiserror::Error, Eq, PartialEq)]
pub enum IdentityError {
    #[error("identifier is empty")]
    Empty,
    #[error("identifier contains a path or URL component: {0}")]
    LocationBearing(String),
    #[error("identifier exceeds {max} bytes (was {actual})")]
    TooLong { max: usize, actual: usize },
    #[error("digest hex is not {expected} lowercase hex characters")]
    MalformedDigest { expected: usize },
}
```

Each of `PackId`, `PackVersionId`, `ArticleKey`, `EntryKey` gets:

```rust
impl PackId {
    pub const MAX_BYTES: usize = 256;
    pub fn parse(raw: impl Into<String>) -> Result<Self, IdentityError>;
    pub fn as_str(&self) -> &str;
}
```

(and the identical shape for the other three).

`parse` MUST reject, in this order:
1. empty or whitespace-only input → `IdentityError::Empty`
2. input longer than `MAX_BYTES` → `IdentityError::TooLong { max, actual }`
3. input that is location-bearing → `IdentityError::LocationBearing(input)`.
   Location-bearing means it contains ANY of: `/`, `\`, `://`, a leading `.`,
   the sequence `..`, a NUL byte, or a Windows drive prefix (an ASCII letter
   followed by `:`).

`ContentDigest` gets:

```rust
impl ContentDigest {
    pub fn sha256_from_hex(hex: impl Into<String>) -> Result<Self, IdentityError>;
    pub fn hex(&self) -> &str;
    pub fn algorithm(&self) -> DigestAlgorithm;
}
```

`sha256_from_hex` accepts exactly 64 characters, each of `0-9a-f`
(lowercase only — an uppercase hex digit is rejected), and otherwise returns
`IdentityError::MalformedDigest { expected: 64 }`.

`DigestAlgorithm` gets `pub fn hex_len(self) -> usize` returning 64 for
`Sha256`.
