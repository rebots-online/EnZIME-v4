# EnZIME Aurora Glass — consumer knowledge reader
Audience: ordinary offline readers, students, field workers, preparedness users. Not a developer workstation.
Canvas #090B13; glass rgba(23,28,44,.72); borders rgba(189,198,255,.14); text #F4F6FF and #B7BDD4; primary #7C8CFF; accent #34E0D4. Broad restrained aurora background.
Inter for ALL interface text and labels; Literata for articles; monospaced numerals only actual sizes/version. Cards 22px radius, fields 14px, buttons comfortably rounded. Reader also uses glass.
Desktop compact left navigation Home Library Ask Notes Memory Settings, top EnZIME Reader and Search. Mobile bottom Home Library Notes More.
NO SYSTEM STATUS UI: no offline-ready badge, online badge, healthy-ready dot, memory mapping, mounted storage pool, root labels, telemetry, terminal panes, fake counts, account avatar, milestone or enterprise tier. No persistent hardware/footer bar. Only real actionable failures at their affected task. Quiet plain version bottom-right without badge or glowing dot.
No fictional data, example titles, generated article text, placeholder tokens, sample purchase amounts or receipts. Empty states must be useful. Data regions are rendered only with actual application inputs.
44px touch targets, visible focus, clear accessible labels, wrapping at text scaling. One obvious primary action; typography, spacing and glass support calm reading.
