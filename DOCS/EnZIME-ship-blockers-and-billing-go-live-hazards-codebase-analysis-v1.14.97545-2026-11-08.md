## 1. Project Profile

- **Product**: enzime-reader — offline-first knowledge reader for ZIM archives / EnZIME DynDon packs; Linux (deb/rpm/AppImage), Windows (NSIS), Android, web targets.
- **Stack**: Tauri 2 shell (`apps/reader/src-tauri`), React 19 + Vite + TypeScript + zustand renderer (`apps/reader/src`), Rust workspace (20 crates + vendored `anzimmerman` + shell), SQLite, zero-dependency TypeScript billing service (`services/billing`, Netlify Function + Chargebee), GA4 Measurement Protocol analytics from Rust.
- **Actual architecture (current)**: renderer → `services/*.ts` (five per-service `call()` wrappers over `invoke`) → 40 registered Tauri commands (`apps/reader/src-tauri/src/lib.rs:72-117`) → `ipc/{home,library,reader,rows,kiwix,annotations,dyndon/*}.rs` + `billing.rs` + `analytics.rs` + `settings.rs` → `AppState`. Production read path is `DiskPackStore` (per-pack SQLite + cluster files) via `RangeZimArchive`; the full-file engine is test-only now. The `application` layer is reached for one module only (`annotation_assets`).
